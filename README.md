# Florida Man

A ridiculous retro side-scrolling Android arcade game about the misadventures of Florida Man.

## First playable prototype
**Level 1: Pool Noodle Panic**

Florida Man fights rabid flamingos with a pool noodle. Current prototype includes landscape fullscreen play, movement, jumping, pool-noodle attacks, flamingo combat, score, and a **Hold My Beer** health meter.

Built as a native Android prototype with no source-storage permissions.
